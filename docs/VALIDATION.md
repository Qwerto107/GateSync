## 自动化测试覆盖的关键边界

- 新规则添加失败或核验不完整时保留旧规则。
- 新增前必须先保存本地台账，持久化失败不写云端。
- 不删除其他备注规则，也不删除有同样备注但不在本地台账内的规则。
- 重复同步不重复创建；创建成功但响应丢失时可恢复。
- 删除版本冲突时停止；撤销失败保留账号和目标记录。
- 部分账号撤销失败时，已撤销目标停用自动同步，避免重新开放。
- 动态目标在无可用公网 IP 时仍可撤销已有规则。
- 云凭证加密、API 不回显密钥、主密钥丢失时拒绝启动。
- 未登录拒绝访问、退出后会话失效、CSRF 校验。
- 拒绝未发起的 Google OAuth 回调。
- IPv4、端口、检测源 URL、Cron 与 CSV 公式转义校验。
