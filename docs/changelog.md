# 更新记录

[文档中心](README.md) · [项目首页](../README.md) · [发布流程](releasing.md)

## 未发布

- 新增通知渠道，首版支持多个飞书自定义机器人、IP 变更与同步失败事件、签名校验、自定义卡片 JSON 和测试发送；后台队列支持有限重试及重启恢复，发送结果写入日志。
- 新增规则实际变更成功通知；同一轮同步按渠道订阅合并 IP 变化、成功及失败结果，支持独立的合并卡片模板和目标摘要。
- 同步通知按目标独立分块，状态与规则明细使用颜色区分，删除规则增加删除线；缩短错误摘要，完成信息独立展示。
- 日志支持自定义日期时间范围，按浏览器本地时区选择，默认最近 12 小时，提供 12h / 1d / 3d / 7d 快选；列表、折叠明细及 CSV 使用相同范围。
- 系统设置支持手动输入日志保留天数，新安装默认 180 天，已有安装升级默认 0（永久保留）；后台每日清理，独立保存不退出登录。
- 操作日志与计划任务执行记录默认折叠连续的相同 IP 无变化日志，聚合后分页，支持展开原始明细；CSV 仍逐条导出。

## v0.1.1 · 2026-11-09

- 检测频率增加 10、30、60 分钟预设，支持自定义 1–10080 分钟整数间隔，保留五段 Cron。

- 定时任务仅在公网 IP 变化时自动同步一次，地址未变时不核对云端规则；检测失败保留旧规则，同一 IP 同步失败可手动重试。
- 修复展开额外端口时，其他端口标签被拉高的问题。
- README 顶部增加应用图标。

## v0.1.0 · 2026-11-09

### 功能

- 地域及其他下拉统一使用自定义控件，地域支持中文名、代码搜索和手动输入。
- 放行目标支持独立名称、拖拽及上移下移排序，顺序自动保存；列表采用紧凑行高。

- 公网 IP 查询支持手动同步、定时任务分别勾选，保存目标只使用缓存。
- 云权限错误显示具体接口、服务端拒绝的 action 或明确标注的排查提示，以及 RequestId。

- 一个目标可同时包含自动公网 IP 与多个自定义 IP，地址去重并共用端口；检测失败保留旧规则。
- 云端备注使用目标备注与简短稳定标记，兼容旧规则并支持原地更新备注。

- 支持 Lighthouse 实例防火墙，与安全组共用先增后删及归属保护流程。
- 按服务动态获取可用地域，读取失败保留手动输入。
- 站点地址、Google OAuth、白名单和访问密码移至后台，任务时区在后台设置。
- Compose 可直接从 GitHub 下载，默认使用 GHCR 镜像、13850 端口和 ./data 目录绑定。
- 提供安全组和 Lighthouse 的 CAM 策略 JSON。

- 腾讯云多账号、独立地域、安全组选择或手填 ID。
- TCP / UDP 单端口与端口范围，动态公网 IPv4 或固定 CIDR。
- 单个及全部目标手动同步、可配置间隔或 Cron 的自动同步。
- 访问密码与 Google OAuth 邮箱白名单，凭证加密保存。
- 操作日志、规则变更明细、筛选与 CSV 导出。
- 中文界面、浅色和深色主题、窄屏布局。

### 修复
