## 登录

首次使用初始化密码登录，之后可在“系统设置”中修改访问密码或配置 Google 登录。Google 仅允许已验证且完整邮箱匹配白名单的账号；配置方法见 [部署指南](deployment.md#google-oauth)。

勾选“在此设备上保持登录 7 天”后，会话最多保留 7 天。未勾选或使用 Google 登录时，会话最多 12 小时。退出登录会撤销当前会话；服务重启会使所有已有会话失效。所有授权用户均具有管理权限。

## 云账号

在“云账号”中配置云厂商访问凭证、名称、默认目标类型和地域。当前支持腾讯云，凭证为 SecretId / SecretKey。默认类型可选 VPC 安全组或 Lighthouse 防火墙，用于连接测试和新目标的初始选择；同一账号仍可创建两类目标。

地域由对应服务动态查询，只展示 AVAILABLE 的地域：安全组使用 CVM DescribeRegions，Lighthouse 使用其自身 DescribeRegions。添加账号时点击“读取可用地域”，添加目标时按账号和目标类型自动读取。地域下拉可按中文名或代码搜索，展开时展示完整列表；查询失败仍可输入地域代码并选择“使用手动输入”。`ap-guangzhou` 仅为初始默认值，同一账号可以为不同地域创建目标，不以固定地域表替代真实结果。

建议使用专用 CAM 子账号；可复制的权限 JSON、调用的操作及资源范围见 [CAM 授权](cam.md)。连接测试只验证当前默认类型的读取权限，不创建测试规则。写入权限在实际同步时验证。密钥加密保存，SecretKey 不回显，编辑时密钥留空保留原值。

## 放行目标

1. 按需填写目标名称（最多 60 个字符），再选择目标类型、账号、地域及安全组或 Lighthouse 实例；也可手动输入 sg- 或 lhins- 开头的资源 ID。实际同步仍须具备对应权限。
2. 添加 TCP / UDP 端口，支持单端口和范围，如 `22`、`8000-8100`；端口值为 1–65535，每个目标最多 50 项。
3. 勾选一个或多个 IP 来源：“跟随当前公网 IP”与“自定义 IP”可以同时选择。自定义列表支持多个 IPv4 / CIDR，每项可填写名称，最多 20 项。
   所有来源共用目标端口，规范化后的相同地址自动去重，IP 来源与端口组合最多 100 条。
4. 按需加入自动同步，填写目标备注，保存并同步。云端规则显示该备注并附加简短归属标记，自定义 IP 的名称仅供后台识别。

目标名称仅用于后台识别和搜索，留空时显示云端资源名称或 ID；云端备注仍取目标备注。列表支持拖动手柄排序，也可点击上移、下移，顺序自动保存到后台，刷新后保留。新目标追加到末尾；排序只保存展示顺序，不触发云端同步。端口和 IP 较多时可展开剩余项目，错误详情也可展开查看。

动态 IP 来自运行设备的网络出口，单个 IPv4 转换为 /32；固定网段会规范化为网络地址。不会读取访问者 IP 并自动开放。自动检测不使用 HTTP 代理环境变量，VPN 或透明网关可能改变实际出口。

目标类型、账号、地域和云端资源确定已有目标的归属，编辑时不可更换。更换归属应创建新目标，再按需撤销旧目标。

保存或编辑目标后使用公网 IP 缓存尝试同步，不额外查询出口。缓存为空或上次检测失败时，已有规则保留；可先点击“重新检测”。若同步失败，目标配置会保留，可查看错误并重试。目标的自动同步开关只控制定时任务，手动同步仍可执行。

## 同步行为

- 手动可同步单个目标或全部目标。是否先查询公网 IP 由“计划任务 → 公网 IP 查询 → 手动同步时查询”控制；关闭时使用缓存，全部同步每轮最多查询一次。
- 先保存创建意图，再新增所需规则；重新读取并确认新规则存在后，才删除旧规则。
- 删除必须同时匹配本实例及目标推导出的稳定归属标记、规则条件和本地台账中已知的描述，使用刚读取的规则版本。版本冲突时停止，等待重试。
- 公网 IP 变化时只移除不再需要的动态地址规则，自定义 IP 保留。动态地址同时属于自定义列表时，只生成一份规则，后续仍按固定来源保留。
- IP 检测失败时保留旧规则；固定 IP 可补充同步，但推迟过期规则清理，目标仍显示失败并提示动态部分未完成，恢复检测后再收敛。
- 安全组按版本与索引删除；Lighthouse 按版本及精确规则值删除，匹配无法唯一确认时停止撤销。
- 新规则按对应服务规则顺序加入，已有拒绝规则可能影响实际连通。

规则备注形如 `办公室 SSH [GS:<稳定标记>]`，目标备注留空时使用 GateSync。为兼容服务长度限制，仅截短可读部分，完整保留标记。修改目标备注后，下次同步会原地更新已确认归属规则的云端备注，不改变端口或来源 IP。

旧 `gatesync:<实例ID>:<目标ID>` 规则通过原台账识别并迁移，更新前保存新旧两种描述，防止响应丢失后无法恢复。旧目标的单个固定 IP 自动映射到自定义列表。

请在工具中修改目标备注，不要直接在云控制台修改描述。仅有相同标记但不在台账内的规则不会被接管。原地修改备注需新增 CAM 权限，见 [CAM 授权](cam.md#云端备注更新权限)。

状态含义：

| 状态 | 含义 |
| --- | --- |
| 待同步 | 目标已保存，等待同步 |
| 已同步 | 上次核验的云端规则与目标配置一致 |
| IP 不一致 | 当前检测 IP 与上次同步 IP 不同 |
| 同步失败 | 操作未完成，查看错误或日志后重试 |
| 已撤销 | 云端归属规则已撤销，目标自动同步已关闭 |

删除账号或目标默认保留云端规则，之后需在云控制台管理。勾选撤销时，部分操作失败会保留本地记录；已撤销目标会暂停自动同步，避免重新开放，可再次重试剩余撤销。

## 计划任务

自动同步默认关闭。可选 1 / 5 / 10 / 15 / 30 / 60 分钟预设、自定义 1–10080 分钟整数间隔（最长 7 天），或五段 Cron，例如 `*/5 * * * *`。Cron 使用“计划任务”中保存的 IANA 时区，默认 `Asia/Shanghai`，保存后生效。

“公网 IP 查询”包含独立的“手动同步时查询”和“定时任务时查询”选项，默认均开启。关闭对应选项后，同步使用上次成功查询的缓存；缓存不可用时保留旧规则。页面刷新、切换页面和保存目标均不查询公网 IP，“重新检测”按钮始终主动查询。

定时查询随自动同步计划执行，仅在有已启用自动同步的动态目标时进行；纯固定 IP 目标不会触发检测。

最多配置三个返回纯文本 IPv4 的公开 HTTPS 检测源，按顺序尝试。定时任务只处理已开启自动同步且跟随公网 IP 的目标；地址未变时不调用云端规则接口，地址变化时同步一次，同时保留该目标的固定 IP。纯固定 IP 目标不做定时核对。

每个目标的自动处理地址会持久化，服务重启不会重复触发。已有目标首次以上次同步地址比较；尚无历史地址时只建立基线，等待实际变化。检测失败不访问云端；同一 IP 同步失败后不自动重试，可手动同步。手动同步及保存目标仍会核对规则。

设备须持续在线，进入休眠、关机或停止服务后无法检查。当前不提供通知渠道。

## 操作日志

记录 IP 检测、规则同步、账号和目标变更、计划设置及登录。支持自定义日期时间范围、类型、结果及对象、详情搜索，每页 20 项。规则同步可展开新增、删除明细。

时间范围默认最近 12 小时，可快选 12h / 1d / 3d / 7d。点击起止时间打开自定义日历，可切换年月、点击日期或直接输入日期时间，使用 24 小时制。选择按浏览器本地时区解释，包含开始时间，不包含结束时间。点击“应用时间范围”后生效。刷新快选范围时更新到当前时间，自定义范围保持固定。

操作日志和计划任务执行记录默认折叠连续、相同 IP、相同触发方式的“公网 IP 无变化”记录，显示检测次数与起止时间。聚合后再分页，重复检测不会占满一页。点击“展开检测明细”逐条查看，每次读取 20 条，可继续加载。IP 变化、检测失败和其他操作单独显示，并打断连续分组；折叠不改变保留期内的原始记录。

CSV 导出和展开明细使用当前时间范围及筛选条件。CSV 最多导出最近 10,000 条，时间为 RFC 3339 UTC 格式。页面时间按浏览器本地时区显示。

## 系统设置

可在后台设置公开访问地址、Google OAuth 开关、Client ID / Secret、邮箱白名单和访问密码。Google Secret 加密保存且不回显，留空表示保留已有值。修改访问密码须验证当前密码。

站点与登录设置保存后立即生效，并撤销所有登录会话和未完成的 Google 登录，请重新登录。公开地址不修改监听端口；更换域名、协议或端口后，同时核对 Google 回调 URI。

“日志保留”使用独立输入框，单位为天，0 表示永久保留。新安装默认 180 天，已有安装升级时默认 0，已保存的值在重启后保留。点击“保存日志设置”单独保存，不退出登录，也不会立即删除记录。

后台每 24 小时按保留天数清理一次全部类型的超期日志，不受自动同步开关影响。设备离线时不执行，启动后补做已到期的清理。缩短保留时间前请按需导出；清理后无法恢复，将天数改为 0 只能停止后续清理。

首次初始化后，后台配置保存在 SQLite；后续修改或删除原登录环境变量不会重置它们。
